# Bundled license text copies

The following pinned npm packages omit their repository LICENSE file. These copies
are taken unchanged from the git revisions advertised by `npm view <package>@<version> gitHead`:

- `terra-draw@1.39.0`: [LICENSE at 4a8cfa2](https://github.com/JamesLMilner/terra-draw/blob/4a8cfa2ef2dece2284dd06aa71ed0023d84a5cfb/LICENSE).
- `terra-draw-maplibre-gl-adapter@1.5.0`: [LICENSE at 8757783](https://github.com/JamesLMilner/terra-draw/blob/8757783af8faf3cb75555a9a9b646c72b01a1d43/LICENSE).

`prepare-package.mjs` copies these notices into `dist/THIRD_PARTY_NOTICES.txt` along
with the license and notice files from other packages included in the build.
Review the relevant upstream license again when updating either dependency.
